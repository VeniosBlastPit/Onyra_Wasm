# Official Website

The official Onyra website built from scratch using **Blazor WebAssembly**, **C#**, **HTML**, and **CSS**.

The website serves as a main hub for everything **ONYRA**

## 🚀 Technologies Used

* **Blazor WebAssembly** — Frontend framework
* **C#** — Application logic and components
* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, layout, animations, and responsive design

## ✨ Features

* Responsive design for desktop and mobile devices
* Interactive UI built with Blazor components
* Personal profile and introduction
* Skills and technologies section
* Projects showcase
* About and contact sections
* Custom styling and layouts
* Client-side application powered by WebAssembly

## 🛠️ Getting Started

### Prerequisites

Make sure you have the following installed:

* [.NET SDK](https://dotnet.microsoft.com/download)
* A code editor such as **Visual Studio**, **JetBrains Rider**, or **Visual Studio Code**

### Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
cd your-repository
```

### Run the Project

Restore the dependencies and start the development server:

```bash
dotnet restore
dotnet run
```

The application will be available at the local URL shown in the terminal.
